# Vant Media

Static website for Vant Media, Christchurch billboard and outdoor advertising.

Contact: Shane@vantmedia.site

## Preview

Run `python -m http.server 4173` from this folder, then open http://localhost:4173.

## Publish

GitHub repository: https://github.com/AnalyticsInAction/vant-media

GitHub Pages publishes the root of the `main` branch. No build step, paid hosting, API keys or backend required. Enquiry links open the visitor's email application.

## Artwork

The three campaign images in `assets/` were generated with the built-in Imagegen tool for this website. The brands, advertising locations and campaigns are illustrative, not client case studies or a statement of available inventory.

Final prompt set: realistic documentary photographs of ordinary Christchurch/Canterbury roadside locations, natural overcast light, clean professionally installed charcoal billboard frames and flat, taut matte prints. Port & Plains: muted forest green, cream lettering, coffee photograph, “GOOD MORNINGS. GREAT COFFEE.” Southern Ridge: teal alpine photograph, “TAKE THE LONG WAY HOME.” Flour & Field: red and cream, sourdough photograph, “YOUR DAILY BREAD.” Refinements retained everyday location realism while keeping billboards clean, with Port & Plains specifically adjusted to remove luminous green.

## Editing

`index.html` holds copy and sections; `styles.css` holds responsive styling; `script.js` controls the accessible native dialog gallery. Replace the JPG files in `assets/` to change imagery. Keep campaign disclosures accurate if real photography replaces the generated concepts.
